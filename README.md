# 🚀 OnyxGram Crash Mini App («Ракета»)

Полноценное веб-приложение (Telegram / OnyxGram Mini App) в стиле игры Crash / Aviator с синхронизацией по WebSocket, физикой на HTML5 Canvas, синтезатором звуков и интеграцией с ботом OnyxGram.

---

## 📁 Структура проекта

```
onyxgram_crash/
├── main.py              # Точка входа: одновременный запуск сервера и бота
├── server.py            # Веб-сервер на aiohttp (раздача статики, WebSocket, API)
├── engine.py            # Игровой движок (петля раундов, расчёт краша, симуляция ботов)
├── database.py          # База данных SQLite (aiosqlite: юзеры, балансы, раунды)
├── bot.py               # Бот OnyxGram на aiogram 3.x с кнопкой WebApp
├── start.bat            # Запуск в 1 клик на Windows с открытием браузера
├── .env                 # Конфигурация (BOT_TOKEN, API_BASE, WEBAPP_URL)
└── static/
    ├── index.html       # Мобильный UI (арена, панель ставок, модалки)
    ├── style.css        # Киберпанк-тема, неоновые эффекты, адаптивность
    └── game.js          # Отрисовка ракеты 60 FPS, Web Audio звуки, сокеты
```

---

## 🎮 Как играть и тестировать

1. **В браузере прямо сейчас:**
   * Откройте: [http://localhost:8080](http://localhost:8080)
   * У вас сразу есть стартовые **100 ⭐**.
   * Выбирайте размер ставки (или жмите `+10`, `+25`, `2x`), ставьте «Авто-вывод» при желании.
   * Во время полёта жмите горящую зелёную кнопку **«ЗАБРАТЬ»**, пока ракета не взорвалась!
   * Во вкладке **«🎁 Вывод»** можно вывести выигрыш подарками OnyxGram (`Teddy Bear`, `Space Rocket`, `Diamond` и т.д.).
   * Во вкладке **«+ Пополнить»** можно добавить ещё тестовых звёзд.

2. **Запуск в мобильном приложении OnyxGram:**
   * Поскольку Telegram/OnyxGram WebApp требует обязательный **HTTPS**, для проверки с телефона запустите бесплатный туннель:
     ```bash
     # Через Cloudflare Tunnel (без регистрации):
     cloudflared tunnel --url http://localhost:8080
     ```
     или
     ```bash
     ngrok http 8080
     ```
   * Скопируйте полученную ссылку `https://...` в `.env` параметр `WEBAPP_URL=https://...`
   * Напишите вашему боту в OnyxGram `/start` и нажмите кнопку **«🚀 ИГРАТЬ В РАКЕТУ»**!
